# others

אתר סטטי של כלים לתורת המוזיקה (עברית, RTL). אין build: פותחים את `index.html` בדפדפן.

| קובץ | מה הוא עושה |
| --- | --- |
| `index.html` | דף הבית: חמשה וקישורים לכלים |
| `music_theory_exercise_tool.html` | תרגול אונליין עם השמעה |
| `music_theory_worksheets_generator.html` | דפי תרגול להדפסה ול-PDF |
| `music_theory_algorythm.html` | מחשבון מרווחים, סולמות ואקורדים (כלי עבודה, לא מקושר מדף הבית) |
| `site-nav.js` | סרגל הניווט המשותף לכל הדפים (קישורים לדף הבית ולשלושת החלקים) |
| `theory-core.js` | הלוגיקה המשותפת לכל הדפים: צלילים, קטלוג המבנים, בנייה מצליל נתון, זיהוי מרווחים, סימני מפתח וציור החמשה |

## בדיקות

```
npm install && npx playwright install chromium   # פעם אחת
npm test
```

- `tests/theory-core.test.js`: הלוגיקה המשותפת (בנייה, זיהוי, סימני מפתח).
- `tests/ui.test.js`: הדפים בדפדפן אמיתי, במחשב ובטלפון: כל סוג תרגיל בקריאה ובשמיעה נטען, מנגן ומקבל תשובה נכונה; אימון לפי שלבים, שיתוף, האוסף, דפי התרגול להדפסה והמחשבון. בדיקה נכשלת על כל שגיאת JavaScript בדף.

הבדיקות רצות אוטומטית ב-GitHub על כל PR ועל כל דחיפה ל-main.

דגימות הפסנתר והוויברפון: ראו `sounds/README.md` (ממאגר VCSL, ברישיון CC0).
