# דגימות צליל

דגימות להשמעה בדף התרגול (`music_theory_exercise_tool.html`). כל קובץ הוא צליל אחד ב-MP3 עם דעיכה טבעית: ויברפון מונו של כ-8 שניות, ופסנתר ונבל סטריאו של כ-6 שניות. הצליל הרך מסונתז בדף ואין לו קבצים. הדף מזיז כל צליל בגובה מהדגימה הקרובה אליו.

| תיקייה | מקור | רישיון |
| --- | --- | --- |
| `piano/` | Versilian Community Sample Library, פסנתר כנף Steinway B, מיקרופון קרוב, סטריאו ([sgossner/VCSL](https://github.com/sgossner/VCSL)) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| `harp/` | Versilian Community Sample Library, נבל קונצרטים, mf ([sgossner/VCSL](https://github.com/sgossner/VCSL)) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| `vibraphone/` | Versilian Community Sample Library, ויברפון במקושים קשים ([sgossner/VCSL](https://github.com/sgossner/VCSL)) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

שמות הקבצים הם הגובה הנשמע בכתיב מדעי (C4 = דו אמצעי, `s` = דיאז). בקובצי המקור של VCSL הדו האמצעי נקרא C3, ולכן השמות הוזזו באוקטבה.
