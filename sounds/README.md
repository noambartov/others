# דגימות צליל

דגימות להשמעה בדף התרגול (`music_theory_exercise_tool.html`). כל קובץ הוא צליל אחד, מונו, MP3 של כ-8 שניות עם דעיכה טבעית. הדף מזיז כל צליל בגובה מהדגימה הקרובה אליו.

| תיקייה | מקור | רישיון |
| --- | --- | --- |
| `piano/` | Salamander Grand Piano V3, Alexander Holm (דרך [Tonejs/audio](https://github.com/Tonejs/audio)) | [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| `vibraphone/` | Versilian Community Sample Library, ויברפון במקושים קשים ([sgossner/VCSL](https://github.com/sgossner/VCSL)) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

שמות הקבצים הם הגובה הנשמע בכתיב מדעי (C4 = דו אמצעי, `s` = דיאז). בקובצי המקור של VCSL הדו האמצעי נקרא C3, ולכן השמות הוזזו באוקטבה.
